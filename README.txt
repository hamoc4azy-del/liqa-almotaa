لقاء الموتى V3
نسخة واجهة أكثر تنظيمًا.

الوظائف:
- تصميم غامض/مقابر بألوان داكنة وأحمر وبنفسجي.
- إدخال اسم الشخص وتاريخ الوفاة.
- اختيار نوع التجربة ورسالة اختيارية.
- اقتراح أسماء أثناء الكتابة.
- إنشاء رقم طلب.
- مراحل: الطلب، المراجعة، الموعد، اللقاء.
- موعد رمزي تجريبي يظهر بعد إرسال الطلب.
- تنبيه واضح بأن التجربة فنية وليست تواصلًا حقيقيًا.

مهم للنشر الحقيقي:
هذه النسخة Front-end فقط. لكي يصبح الموقع نظامًا حقيقيًا، نحتاج Backend وقاعدة بيانات ولوحة إدارة ونظام حسابات/مواعيد، ثم ربط توليد الصور بخادم آمن.

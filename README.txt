لقاء الموتى — النسخة الأولى

هذه نسخة Front-end تجريبية تعمل محليًا بدون خادم.
1) افتح index.html في المتصفح.
2) جرّب: أحمد زويل / صلاح جاهين / نجيب محفوظ.

قبل النشر:
- استبدل example.com بالدومين الحقيقي.
- أضف قاعدة بيانات ومصدرًا موثوقًا للبيانات.
- أضف نظام بحث حقيقي.
- أضف توليد الصور من خلال خادم آمن، وليس مفتاح API داخل JavaScript.
- اربط الموقع بـ Google Search Console وأرسل sitemap.xml.
